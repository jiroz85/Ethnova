# 🛒 Ethnova

A full-stack multi-vendor marketplace platform designed to connect customers and sellers in one structured online marketplace.

## ✨ Features

- Customer product browsing
- Product search and filtering
- Seller profiles and product management
- Product image uploads
- Admin dashboard
- Seller management
- User management
- Reports and admin oversight
- Product categories
- Direct seller contact

## 🛠️ Tech Stack

### Frontend

- React
- TypeScript

### Backend

- Node.js
- TypeScript

## 📁 Project Structure

```text
Ethnova/
├── frontend/    # Frontend web application
└── backend/     # Backend API
```

## 🚀 Getting Started

### Prerequisites

- Node.js
- npm

### Clone the repository

```bash
git clone https://github.com/jiroz85/Ethnova.git
cd Ethnova
```

### Backend

```bash
cd backend
npm install
npm run dev
```

### Frontend

Open a new terminal:

```bash
cd frontend
npm install
npm run dev
```
